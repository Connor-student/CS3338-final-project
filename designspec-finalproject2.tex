\section{Project Overview}

The JPL Lunar Detection Pipeline is a machine learning and computer vision
project designed to analyze lunar imagery using object detection and
instance segmentation models. This document focuses specifically on the
packages, dependencies, libraries, and Docker requirements needed to run
the project.

% =========================================================
\section{Programming Language}

\begin{itemize}

\end{itemize}

Python is the primary programming language used for:
\begin{itemize}

% ---------------------------------------------------------
\subsection{Dockerfile}

Example Docker configuration:

\begin{verbatim}
FROM python:3.11-slim

WORKDIR /app

RUN apt-get update && apt-get install -y \
    python3 \
    python3-pip \
    git \
    wget \
    curl \
    build-essential \
    cmake \
    ffmpeg \
    libsm6 \
    libxext6 \
    libgl1 \
    libglib2.0-0 \
    && rm -rf /var/lib/apt/lists/*

COPY requirements.txt .

RUN pip install --no-cache-dir -r requirements.txt

COPY . .

EXPOSE 8000

CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
\end{verbatim}

The JPL Lunar Detection Pipeline depends on multiple machine learning,

process lunar imagery, perform object detection and segmentation,
